# Standing preferences

Answers given once and reused by every run. Agents never guess these; if a field
is blank, they ask.

| Question | Answer |
|---|---|
| Current location | e.g. City, Country |
| Open to remote | Yes / No |
| Open to onsite / relocation | e.g. Yes, to: City A, City B |
| Work authorization | e.g. Citizen of Country X; no sponsorship needed in X |
| Needs visa sponsorship for | e.g. any other country |
| Notice period | e.g. 30 days |
| Open to night shifts or other time zones | Yes / No |
| Expected compensation | See `salary-thresholds.md` |
| Current compensation | e.g. "Prefer to discuss against the role's band" |
